## 已确认的计算机制

1. **数据来源与装备随机属性。** 使用实际运行的游戏安装目录及其数据库。DLC 中同名 DBR 是完整记录覆盖，不能保留新版已经删除的旧字段，否则装备 seed 的随机数顺序也会偏移。武器本体基础物理、额外物理、武器本地平伤、附件和概率 DoT 分别保留其来源。
2. **常驻技能与属性。** 已学习的临时触发被动不等于当前已触发。复仇烈焰的常驻角色属性与反应攻击伤害分开；回火等已学习的常驻光环修正进入角色属性。属性伤害和生命、能量派生读取游戏 DBR 公式，包括初始属性及持续伤害的独立系数。
3. **动画攻速。** 读取角色动画表及 ARC 中的 ANM 帧数、帧率，使用引擎的动画时长汇总与攻速上限顺序。双枪的武器基础速度修正相加，不能按两手平均。`135%` 不是直接拿装备攻速总和相加得到的数值。
4. **转换与局部伤害加成。** 技能转换先于装备转换，已经转换的伤害包不再次转换。技能的局部伤害百分比随其来源伤害包，并按每次转换份额同步缩放；全局加成在最终伤害类型上结算。不能把技能和装备的所有转换率、百分比先合成一个总数。
5. **主攻击与次级攻击。** 火焰打击的主攻击为 `160%` 武器伤害，爆裂打击为独立的 `35%` 次级攻击，不能合并成 `195%` 后整体乘双持次数。当前双枪动画的回调提供两把武器 ID：主攻击使用两手平均与 `1.5` 次数权重，次级攻击累加两把武器的本地伤害，共享平伤只加一次，次级攻击自身也只结算一次。`secondaryWeaponDamageCorrection.*` 保存该专用差额。
6. **面板持续伤害。** DoT 使用自己的持续伤害百分比；装备 DoT 按技能武器伤害比例继承。主攻击在 DPS 入口过滤两手重复来源后应用双持权重，因此不能用第二页显示的每击均值直接乘显示 APS。次级攻击自身的燃烧不乘主攻击的双持次数。面板不乘目标数，也不混入敌人抗性、命中、暴击概率或武器池替换攻击的实战期望。

这些机制由原始 DBR、离线引擎调用路径分析与游戏内换装测量共同验证。探针只读取游戏文件和冻结存档，不向游戏注入代码，也不读取或修改运行进程内存。

## 复现与回归

本地证据位于 `artifacts/panel-dps-validation/probe/`：

- `live64-measurements.json`：游戏 UI 原始观察，包括换装、分类型伤害及技能提示。
- `live64-final.json`、`live64-final-no-right.json`、`live64-final-no-head.json`：同一冻结输入的最终 C# 原始输出。
- `live64-final-repeat.json`：重新启动探针进程后的基线重复运行。
- `live64-final-comparison.json`：独立 Python 按类型重构，逐样本断言与 Core 原始 DPS 的误差小于 `1e-6`。
- `live64-final-verification.json`：五个整数一致、类型均值舍入误差、新进程重复结果和输入文件 SHA 不变的检查结果。

独立新进程再次得到火焰打击 `23478.300394732545`、普通攻击 `4373.8310589494595`，完整 normalized stats 也与第一次相同。四次探针进程使用相同 Core hash；所有冻结输入文件的运行前、后 SHA-256 保持一致。

长期回归不需要游戏安装或私人存档。`tests/GrimDawnOptimizer.Tests/Fixtures/panel-dps-game-observations.json` 只保留五组必要的 normalized stats 和 rotation；没有角色名、个人路径、物品 ID、seed、背包或存档内容。`PanelDpsGameGoldenTests` 使用独立读取的五个游戏显示值作断言：

```powershell
dotnet test tests/GrimDawnOptimizer.Tests/GrimDawnOptimizer.Tests.csproj --filter FullyQualifiedName~PanelDpsGameGoldenTests
```

该 golden fixture 验证最终数值计算。来源读取、随机属性、持久技能、转换、动画、次级武器收集和面板规则另有针对性测试；fixture 本身不代替对这些输入来源的测试。

## 验证范围

本次达到的是这个双枪火焰打击构筑在五组已测状态中的显示一致，不能由此宣称所有职业、技能和装备组合都已完全验证。

- 特殊动画若只有 `RightHandHit` 或 `LeftHandHit` 回调，次级攻击可能只收集指定手的武器。当前验证的男女双枪普通攻击动画均提供双手回调；尚未建立所有特殊动画的回调元数据覆盖。
- 纯 `0%` 武器伤害法术已有机制测试，未完成游戏内样本验证；其他蓄力、多投射物、召唤物、临时 Buff、特殊 DoT 转换及全套武器池组合仍需扩大样本。
- 常驻修正技能的父子识别目前使用同目录的编号技能族规则。已确认回火，不代表异名或复杂自定义技能树的所有连接都已覆盖。
- 该报告针对角色面板 DPS。护甲显示、防御能力和回复等其他面板字段仍有独立差异；本次结果也不证明实战 DPS、目标减伤或触发覆盖率已经与游戏完全一致。
